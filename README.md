# Service-Hub

Platformă de programări auto: clienții își găsesc service-ul, se programează online și aprobă devizul în aplicație; service-urile își gestionează programările, devizele și istoricul. Domeniu: service-hub.ro.

Aplicația se construiește cu Claude, în secțiunea Code, sarcină cu sarcină.

**Începe cu [`PORNIRE.md`](PORNIRE.md).**
